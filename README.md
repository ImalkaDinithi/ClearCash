# ClearCash – Expense Tracking Application

## 📖 Overview

ClearCash is a full-stack expense tracking application that helps users efficiently manage their personal finances. The platform allows users to track income and expenses, monitor spending habits, and visualize financial data through an intuitive dashboard.

Built with a modern technology stack, ClearCash focuses on security, performance, responsiveness, and scalability to provide a seamless user experience across devices.

---

## ✨ Features

### User Authentication
- Secure user registration and login
- Protected routes and user sessions
- Password encryption for enhanced security

### Expense Management
- Add new transactions
- Edit existing transactions
- Delete transactions
- Categorize income and expenses
- Track financial activities in real time

### Dashboard & Analytics
- Financial overview dashboard
- Income and expense summaries
- Visual representation of spending patterns
- Interactive charts and statistics

### Responsive Design
- Mobile-friendly interface
- Optimized for desktop, tablet, and mobile devices
- Modern and clean user experience

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

- Node.js
- npm
- MongoDB

---

### Clone the Repository

```bash
git clone https://github.com/ImalkaDinithi/ClearCash.git
cd ClearCash
```

---

### Install Dependencies

#### Frontend

```bash
cd frontend/expense-tracker
npm install
```

#### Backend

```bash
cd ../backend
npm install
```

---

## ⚙️ Environment Variables

Create a `.env` file inside the `backend` directory:

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key
```

---

## ▶️ Running the Application

### Start the Backend Server

```bash
cd frontend/expense-tracker
npm start
```

### Start the Frontend Application

```bash
cd backend
npm run dev
```
